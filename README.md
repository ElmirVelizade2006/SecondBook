# 📚 SecondBook

SecondBook is a second-hand book marketplace built with Laravel.  
Users can discover, buy and sell used books through a simple and modern platform.

## 🚀 Features

### 👤 User Features
- User registration and authentication
- Browse books
- Search books
- View book details
- Send book requests
- Leave reviews

### 🛠️ Admin Panel
- Dashboard statistics
- Manage books
- Manage categories
- Manage authors
- Manage publishers
- Manage users
- Manage orders
- Manage reviews
- System settings

## 🖥️ Technologies

- Laravel 10
- PHP 8.1+
- MySQL
- Bootstrap 5
- JavaScript
- HTML5
- CSS3
